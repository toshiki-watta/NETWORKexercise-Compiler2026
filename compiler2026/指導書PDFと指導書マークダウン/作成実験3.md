# 作成実験3：数式拡張（トップダウン構文解析）実装方針

演算子の優先順位（乗除 > 加減）とカッコ `()` のネストに対応するため、現在の `eval_to_r0` を廃止し、再帰下降構文解析による `expression`, `term`, `factor` の3階層構造を実装する。

## 📋 1. 前期準備と現在のコードの整理

- [ ] 今後実装する `expression()`, `term()`, `factor()` のプロトタイプ宣言を `parse.c` の上部に追加する

## 📋 2. 構文解析関数の実装（ボトムアップに記述、トップダウンに解析）
指導書の図15の構文図をそのままC言語の関数に落とし込む。

- [ ] **`factor(void)` の実装（最下層：因子）**
  - [ ] 識別子（変数）の場合 ➔ `load r0 [アドレス]` を出力して `getsym()`
  - [ ] 数値（NUMBER）の場合 ➔ `loadi r0 [値]` を出力して `getsym()`
  - [ ] 開きカッコ `(` の場合 ➔ `getsym()` で消費後、再帰的に `expression()` を呼び出し、戻ってきたら閉じカッコ `)` があるかチェックして `getsym()`
- [ ] **`term(void)` の実装（中間層：項、`*`, `div` の処理）**
  - [ ] 最初に `factor()` を呼び出す（結果は `r0` に入る）
  - [ ] `while (tok.value == TIMES || tok.value == DIV)` のループを回す
    - [ ] `r0` の値を一時レジスタ（`r1` など）に退避、またはスタック（あれば）に逃がすコードを出力
    - [ ] 演算子を消費（`getsym()`）し、次の `factor()` を呼び出す（結果が `r0` に入る）
    - [ ] 退避していた値と `r0` を使って、乗算（`mul`）や除算（`div`）の命令を出力する
- [ ] **`expression(void)` の実装（最上層：式、`+`, `-` の処理）**
  - [ ] 最初に `term()` を呼び出す（結果は `r0` に入る）
  - [ ] `while (tok.value == PLUS || tok.value == MINUS)` のループを回す
    - [ ] `term()` と同様に、`r0` を一時退避させてから演算子を消費し、次の `term()` を呼び出す
    - [ ] 加算（`add`）や減算（`sub`）の命令を出力する

##　 作成実験3：数式の構文規則 (図15より)

expression ::= term { ( "+" | "-" ) term }

term       ::= factor { ( "*" | "div" ) factor }

factor     ::= IDENTIFIER 
             | NUMBER 
             | "(" expression ")"
